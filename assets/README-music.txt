HOW TO MAKE "PALAGI" PLAY
=========================

1. Copy your legally obtained song file into this folder.
2. Rename it exactly to:

   palagi.mp3

3. Refresh the website and press ▶ PLAY.

Right now there is a soft placeholder tone:
   palagi.wav

The site will use palagi.mp3 first (if present), then fall back to palagi.wav.

TIP: Open the site with Live Server (or any local server), not always via file://
if the browser blocks media.
